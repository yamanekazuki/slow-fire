## 推奨の使い方（発注時の目安）
- **Tシャツ**: 背中に大きくロゴ（幅28cm前後）、胸は炎マークのみ小さく（左胸5cm）
- **エプロン**: 胸当て中央にロゴ幅18cm前後。生地はチャコール/ブラウン系（cream-on-dark版）
- **耐熱グローブ**: 手首カフ部分に白1色版を幅6〜8cm（刺繍なら白糸1色）
- **グリルシール**: 丸ステッカー60mm。高温部の蓋天面は避け、蓋側面/脚/テーブルに貼る（耐候ラミ必須）
