### 運用メモ

- 新しい写真を足すときは、チラシ正本の `ph/` にあるオリジナル（リサイズ前）から持ってくる。
  リサイズ済みの流用はやめる（A1級だと解像度が効いてくる）。
- 差し替えたら、各HTML末尾の【印刷指示】にある実効dpiの記載も必ず更新する。
  実効dpi = 使用ピクセル数 ÷ 出力インチ数。補間で水増しした見かけの数字は書かない。
- デザイン規則は据え置き: 片側アクセント帯（border-left / border-top）は使わない。
  写真上の可読性は全面スクリム（グラデーション）で確保する。
